- M-001 · 2026-11-13 · src: Inception retrospective · Rule: Testes jamais tocam hardware real; chamadas a ddcutil/gsettings passam só por adaptadores mockáveis. · Why: evitar alterar monitores reais durante testes.
- ~~M-002~~ (retired 2026-11-17, superseded by M-004) · Rule: Escritas DDC apenas nos VCP 0x10, 0x16, 0x18 e 0x1A (brilho e ganho RGB), sempre com clamp. · Why: outras features variam por fabricante e podem desconfigurar o monitor.
- M-003 · 2026-11-13 · src: user request (UNIT-0 amendment) · Rule: Everything in the repository (code, comments, CLI/log messages, README, generated TOML comments) is written in English; only the .aidlc documents follow the user's language setting (pt-BR). · Why: the project must be usable by people on other computers.
- M-004 · 2026-11-17 · src: Inception retrospective (261117-tui-software-color) · Rule: DDC writes only VCP 0x10 (brightness), always clamped; RGB gains (0x16/0x18/0x1A) are written only by an explicit, confirmed `reset-ddc`. · Why: nothing must be left persisted in the monitor hardware (supersedes M-002).
- M-005 · 2026-11-17 · src: Inception retrospective (261117-tui-software-color) · Rule: Color and brightness are applied in software (gamma ramps); on stop the identity ramp is restored and nothing stays in the hardware. · Why: night state leaked to other computers through the monitor's memory.
